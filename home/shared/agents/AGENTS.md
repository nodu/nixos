## Notes and memory

- My notes and todos are in SilverBullet; check it when I mention notes, todos or past plans. Don't write to the `memory/` folder through SilverBullet; basic-memory manages it.
- At the start of a task, search basic-memory for relevant notes; when you learn something durable (decisions, gotchas, preferences), write or update a note.
- basic-memory is self-hosted with no cloud account: use the default project, and skip workspace and cloud tools (`list_workspaces` etc.).
- When saving a memory, use the basic-memory MCP, not Claude Code's built-in memory files or any other harness-specific memory. This keeps one store that every harness can read. Never save secrets, tokens or passwords there.
